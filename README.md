# Caesar Cipher Python Tool

This is a simple Python-based Caesar Cipher tool that allows users to **encrypt** and **decrypt** text by shifting characters by a specified number of positions.

# 🔐 What is Caesar Cipher?

The Caesar Cipher is a basic encryption technique where each letter in a message is shifted by a certain number of places in the alphabet. For example, with a shift of 3, "A" becomes "D", "B" becomes "E", and so on.

# 🚀 Features

- Encrypt messages with a shift value
- Decrypt messages with a shift value
- Handles uppercase, lowercase letters, and keeps non-alphabetic characters unchanged
